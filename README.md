Taxi Buddy 🚖
A responsive taxi booking website with a live embedded widget.

Files
index.html — Main page structure

style.css — Styling and responsive layout

script.js — Date/time, popup notifications, animations

Features
🕐 Live date & time (updates every second)

🟢 Blinking LIVE badge

🖼️ Centered round logo with brand name & slogan

📅 Booking widget (embedded, full-width)

⭐ Random booking popup every 2 minutes (name, route, 5-star rating)

💳 Payment methods with icons

🔧 Services section with hover animations

📱 Fully responsive (desktop, tablet, mobile)

Setup
Place all 3 files in the same folder.

Open index.html in a browser.

No build tools required.

Notes
Widget loads from tpwgt.com

Icons via Font Awesome CDN

All content in English
